5. Data loss explanation

For a real bucket, a change that requires replacement can destroy the existing resource and create a new one. If the old bucket contained data, that data could be lost if it was not backed up or migrated first.

In this lab, changing the content of the local_file resource produced a -/+ replacement. Changing the filename after that produced a + create plan because the previous content change had not been applied, so Terraform was still tracking the original web.txt resource and planned the new web-server.txt resource separately.
